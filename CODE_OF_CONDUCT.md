# Contributor Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in this project a respectful, professional, and harassment-free experience for everyone.

This project is expected to remain engineering-focused: evidence, quality, safety, and respectful disagreement matter more than ego, status, or personal attacks.

## Expected Behavior

Examples of behavior that contributes to a positive project environment include:

- Using respectful and professional language.
- Giving and accepting constructive technical feedback.
- Focusing criticism on code, architecture, tests, documentation, and decisions rather than people.
- Being accountable when mistakes are found.
- Helping keep discussions evidence-based and relevant to the project.

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment, intimidation, threats, or personal insults.
- Discriminatory comments or conduct.
- Trolling, repeated disruption, or bad-faith arguments.
- Publishing private information without explicit permission.
- Any behavior that would reasonably make contributors feel unsafe or unwelcome.

## Scope

This Code of Conduct applies in all project spaces, including:

- GitHub issues, pull requests, reviews, discussions, and comments.
- Documentation and project communication channels.
- Any public or private context where someone is representing the project.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying standards of acceptable behavior and may take appropriate and fair corrective action in response to behavior they determine to be inappropriate, threatening, offensive, or harmful.

Maintainers may remove, edit, or reject comments, commits, code, wiki edits, issues, pull requests, or other contributions that are not aligned with this Code of Conduct.

## Enforcement Actions

Depending on severity and impact, maintainers may take actions such as:

1. **Correction** — private or public clarification of why behavior was inappropriate.
2. **Warning** — a formal warning with expected behavior changes.
3. **Temporary restriction** — temporary limitation from participating in project spaces.
4. **Permanent restriction** — permanent removal from participation in the project.

## Reporting

To report behavior that violates this Code of Conduct, contact the repository maintainers through the available GitHub profile or repository communication channels.

Reports should include enough context for maintainers to review the situation fairly, such as links to issues, pull requests, comments, screenshots, or a concise timeline of events.

Maintainers should handle reports with appropriate confidentiality and avoid unnecessary public exposure of personal details.
