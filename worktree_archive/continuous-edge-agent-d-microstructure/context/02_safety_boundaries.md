# Safety Boundaries

**PROHIBITED MODIFICATIONS:**
- broker clients
- order placement
- manual approval
- live execution
- production strategy code or thresholds
- production risk
- feed freshness
- ranking
- TradeBuilder
- dashboard
- Telegram
- credentials
- environment files
- deployment
- production model loading
- live retraining
- production option routing

**PROHIBITED ACTIONS:**
- broker API calls
- WebSocket calls
- production-ledger writes
- locked outcome access
- git add -A
- committing secrets, datasets, caches, or large evidence outputs
