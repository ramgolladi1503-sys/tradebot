# Causality and Truncation Proof Report

## 1. Causal Feature Extraction Proof
All features generated by `extract_features` rely strictly on completed NIFTY/BANKNIFTY bars from `09:15` to `14:45` IST. No future information beyond `14:45` IST is accessed.
* Opening window metrics slice: `[09:15:00, 09:44:00]`
* Decision close: exactly at `14:45:00`
* Typical price anchor mean: `timestamp <= 14:45:00`

## 2. Future Mutation Invariance
We ran `test_causality_and_mutation` where we copied the session data and mutated the close prices of all bars strictly after `14:45:00` (e.g. at 14:46:00 and beyond) to `999.0`.
* **Result**: `candidate_accepted`, `direction`, and `candidate_fingerprint` were completely unchanged between the original and mutated data.
* **Explanation**: Because the quality validation and feature calculations slice the dataframes to `<= 14:45` before processing, any changes after `14:45` are completely ignored.

## 3. Truncated Input Equivalence
We also verified that truncating the dataframe at `14:45` (i.e. removing all rows > 14:45) produces identical candidate decisions and fingerprints.
* **Result**: Passed. The candidate fingerprint matches exactly.
