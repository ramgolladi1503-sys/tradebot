# PR #758 Agent Review Evidence

## Agent Work Contract

Harden TradeBuilder and orchestration authority without changing feed, broker, risk, strategy formulas, ranking weights, or order-routing behavior. Work is limited to characterization, immutable decision contracts, static authority inspection, stage extraction seams, deterministic replay comparison, corpus audit, and focused CI.

## Scope Guard

Allowed:
- read-only execution-decision inference;
- golden-master comparison;
- helper parity proof;
- shadow-cycle comparison;
- AST-based ranking/execution authority inspection;
- stage-pipeline facades with no production routing change;
- deterministic tests and corpus-quality audit;
- CI and documentation.

Forbidden:
- feed implementation changes;
- websocket, freshness, recovery, or subscription changes;
- broker calls or order placement;
- strategy threshold or formula changes;
- ranking-weight changes;
- advisory-to-executable promotion;
- merge or production enablement from this PR alone.

## Grill Me Review

1. Could the shadow contract upgrade an advisory or blocked candidate? Tests require blockers, stale/untrusted quotes, fallbacks, soft rejects, missing execution entries, and contradictory state to remain non-executable.
2. Could helper consolidation change semantics? Legacy helpers remain present and are compared against canonical helpers before any removal.
3. Could extraction reorder, duplicate, or drop candidates? Stage-pipeline tests preserve input order and cardinality and treat mismatches as failures.
4. Could ranking be mistaken for execution authority? The AST authority audit only marks authority proven when a ranking result is directly consumed by an execution call; reporting-only ranking is explicitly not sufficient.
5. Could the Kite corpus falsely certify runtime robustness? Raw underlying candles are accepted only as replay/data-quality inputs; mock option files and non-candidate rows cannot certify TradeBuilder or orchestrator semantics.

## Hermes Review

Interfaces are explicit and deterministic. Evidence structures are serializable, pure, and side-effect free. The new modules do not import or invoke live broker/feed paths. Public outputs include row counts, mismatch counts, parity rates, state distributions, file paths, and authority verdicts.
