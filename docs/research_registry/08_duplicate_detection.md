# Duplicate Detection

No duplicate IDs allowed by registry design.

## Mechanism-Level Deduplication — 2026-08-27

Different strategy names are not automatically independent discoveries. External corpus entries must be compared by economic/structural mechanism, causal feature set, event definition, horizon, and conditioning variables.

### Classification states

- `DUPLICATE`: same economic mechanism and materially same causal specification.
- `RELATED_BUT_DISTINCT`: same broad family but materially different state variable, conditioning mechanism, event construction, or falsifiable prediction.
- `MERGE_WITH_EXISTING_FAMILY`: preserve provenance but do not count as an independent search-family discovery.
- `PREVIOUSLY_FAILED`: mechanism/specification already rejected with applicable evidence; do not retest without materially new mechanism/data/specification.
- `DATA_BLOCKED`: concept is valid to preserve but current authoritative data cannot test it.

## Search-Pressure Rule

Every materially tested parameterization, horizon, feature subset, regime split, strategy variant, and post-hoc condition must count toward selection pressure. Renaming a failed mechanism does not reset search pressure.
