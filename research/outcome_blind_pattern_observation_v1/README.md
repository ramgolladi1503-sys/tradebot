# Outcome-Blind Pattern Observation V1

This campaign observes recurring historical market states before naming or testing a trading hypothesis.

The profile stage:

- reads physical Git LFS evidence only;
- separates pre-outcome fields from future, entry, exit, label, P&L and holdout fields;
- does not calculate returns or profitability;
- does not select CE or PE;
- does not name a strategy;
- does not open validation or holdout data.

A later observation stage may freeze recurring and chronologically stable patterns using only pre-outcome state frequency, persistence and transition structure. Outcome attachment is prohibited until those patterns are frozen.

Research only. No paper or live authorization.
