# Evidence Registry Schema

Each evidence record must contain:

- Evidence ID
- Version
- Evidence type: supporting / contradicting / null / attack / invalidation / reproduction
- Linked Claim ID(s)
- Experiment ID
- Dataset ID(s)
- Artifact path(s)
- Artifact hash(es)
- Procedure/code reference
- Observation summary
- Statistical summary
- Scope of inference
- Assumptions
- Known weaknesses
- Independence relationship to other evidence
- Reproduction status
- Validity status: admissible / provisional / invalidated
- Authority contribution
- Created timestamp
- Owner

Evidence is not a conclusion. The record must distinguish the observed artifact from the interpretation attached to it.
