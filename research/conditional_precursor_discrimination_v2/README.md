# Conditional Precursor Discrimination V2

Research-only continuation of the reverse-causal option-expansion campaign.

The campaign tests whether causal context distinguishes successful precursor occurrences from structurally similar near misses. It does not modify production trading code and cannot certify execution without authoritative timestamp-aligned spread or quote evidence.

Principal focus: `compression_to_expansion_sequence`, followed by response asymmetry and divergence/catch-up families.
