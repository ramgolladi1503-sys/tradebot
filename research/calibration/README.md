# Certifier Calibration Area

This directory is reserved for M2 calibration specifications, experiment records, evidence, and reports.

Sprint-001 defines the governance requirement for calibration but does not execute or claim calibration.

Planned M2 calibration families:

- synthetic edge recovery;
- null worlds;
- power analysis;
- false-positive analysis;
- false-negative analysis;
- representation audit;
- multiplicity audit.

Any future calibration result must receive Calibration, Experiment, Dataset, and Evidence IDs as applicable and must state its valid operating scope.
